# 基线 v1：接收分词 golden 回归记录（P1：否定合并 + 功能词过滤）

> 对照 [baseline-v0.md](./baseline-v0.md)。本次为第一次算法改进（P1 阶段一），
> 改动全部收敛在 `src/utils/text-to-image-matcher.ts` 预处理层，`segmentText` 未动。

- **记录日期**：2026-09-07
- **golden 集**：`scripts/golden/golden-set.json`（v1 schema，20 条，39 个有图内容词，1 个图库缺口）
- **被测代码改动**：
  1. `mergeNegation()`：单字否定词（不/没/别/勿/莫/未）与其后 token 合成否定复合词，
     防止 Intl 拆出正面词导致语义反转（如 "不开心"→p_happy）。
  2. `FUNCTION_WORDS` 过滤：需要/要/该/应该/感觉/好像/起来/下来/上来/上去/下去
     作为功能词剔除，消除误出图（如 "需要"→p_need_want、"起来/下来"→p_come）。
  3. `run-golden.ts` 反作弊判定收紧：仅"整句原样成单 token"才计，避免功能词过滤后误报。
- **复现命令**：同 v0。

**本轮未解决（分词粒度，供下一步贪心分词处理）：**

| id | 句子 | miss | 根因 |
|---|---|---|---|
| rec-002 | 需要喝水吗 | `喝→p_drink` | Intl 合成"喝水"，命中 p_water（含"喝"义）但"喝"无独立 token |
| rec-008 | 你头疼吗 | `头`/`疼` | Intl 合成"头疼"，命中整图 p_headache（**标注待复核：整图 vs 拆两图**） |
| rec-014 | 你睡了吗 | `睡→p_sleep` | Intl 合成"睡了"，无整图 |
| rec-016 | 该吃饭了 | `饭→p_rice` | Intl 合成"吃饭"，命中 p_eat 但"饭"无独立 token |
| rec-017/018 | 把手…/坐… | `来`→p_come | 趋向补语"来"独立成 token 误出图 |
| rec-017 | 把手抬起来 | `手→p_hand` | "把手"整 token，"手"被吞 |
| rec-020 | 医生来看你了 | `来`/`看` | Intl 合成"来看"，无整图 |

> 这 7 条 miss 的根因高度一致：**分词由《Intl.Segmenter 语言习惯》决定，而非《图库词表》驱动**。
> 原句子 token 被合成或拆出的词，和词库的词语不一致。这是 P1 贪心分词要解决的直接对象。
