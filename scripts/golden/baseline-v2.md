# 基线 v2：接收分词 golden 回归记录（P1：none-token 图库贪心拆解）

> 对照 [baseline-v1.md](./baseline-v1.md)。本次为 P1 阶段二：对**未命中（none）**的 token
> 用图库词表做正向最大匹配拆解。改动仍在 `src/utils/text-to-image-matcher.ts`。

- **记录日期**：2026-09-07
- **golden 集**：`scripts/golden/golden-set.json`（v1 schema，20 条，39 个有图内容词）
- **被测代码改动**：
  1. `VOCAB`：图库词表（label.zh + synonyms）。
  2. `splitByLexicon()`：正向最大匹配拆解（maxLen 4）。
  3. `matchToken()`：把单 token 的 5 级匹配抽成可复用函数。
  4. 主循环：token 未命中且图库能从中拆出 ≥2 词时，拆成各图库词再匹配；
     已命中的 token（含合规整体图如"头疼"/"肚子疼"）一律不拆，避免粒度回归。
  5. `MINOR_WORDS`：拆出的单字虚词碎片（了/的/吧/把/着…）直接丢弃。
- **复现命令**：同 v0/v1。

## 剩余 miss（3 条同一根因：整合词粒度冲突）

| id | 句子 | miss | 说明 |
|---|---|---|---|
| rec-002 | 需要喝水吗 | `喝→p_drink` | "喝水"是图库整合 synonym（命中 p_water），贪心不拆 |
| rec-008 | 你头疼吗 | `头`/`疼` | "头疼"是图库整合词（命中 p_headache） |
| rec-016 | 该吃饭了 | `饭→p_rice` | "吃饭"是图库整合词（命中 p_eat） |

> 这三条不再被贪心触及，因为它们在词表里本就是合法整体图（触发的是 synonym 命中而非 none）。
> 唯一出路是**产品拍板**：golden 期望该用"整合整图"还是"拆成原子内容词"。

## 残留误出图（下一待办）

  需"动词+来/去 = 趋向补语"识别，与"医生来看你"里作动词的"来"区分。
