### 2.3 精度噪声 33 个：三类来源

1. **复合词拆散产生的半截图**（约 25 个）：吃药→p_eat+p_medicine、肚子疼→p_belly+p_pain、公交车/救护车→p_car、看电视→p_see+p_television、康复训练→p_rehab、换衣服→a_change_clothes+p_clothes… → P1 整体切出后自然消失

3. **坐下来→p_come**（rec-018）：「来」作为趋向补语漏出 → 图库补 坐下来

> 已确认：rec-065 走→p_go 属 altIds 命中（run-golden.ts 中 altIds 同时计入召回与精度），**不算精度损失，无需改评估口径**。

## 三、阶段 A：P1 词表贪心预分词（最大杠杆，收益约 80%）

### 3.1 改动点

**`src/utils/text-to-image-matcher.ts` 主改**：

- 新增 `vocabSegment(sentence)`：基于词表（labels.zh + synonyms，maxLen=4）的**正向最大匹配（FMM）**，作为主切分；Intl 降级为兜底。
- 新管线顺序：

```
vocabSegment → 正反问折叠(阶段B) → mergeNegation → 去功能词 → 5级匹配 + splitByLexicon 兜底
```

- 保留 `mergeNegation` 与 `splitByLexicon`（对贪心残余的否定/未命中 token 继续兜底）。

**配套图库/词表小补**：

| 词 | 处置 | 目的 |
|---|---|---|
| 坐下来 | `p_sit` 补同义词 | 消除 坐下来→p_come |
| 一下 | 加入「切后丢弃词」 | 消除 休息一下→d_below（量一下/等一下等已被更长词优先合并，不会误伤） |
| 我们/咱们 | 加入「切后丢弃词」**且加入切分词表** | golden 口径=功能词无图；先整词切出再丢弃，避免拆成 我/们 后 我(p_i) 漏出 |

### 3.2 预期效果

- 救回 14/15 处未召回（rec-002 见阶段 C 的口径小修）
- 消灭约 25 个噪声图
- 阶段 A 验收：**召回 ≥97%、精度 ≥85%、85 条零回归**

## 四、阶段 B：P2 正反问/否定处理

- 新增**正反问折叠**：检测 **A不A** 模式（饿不饿→饿、麻不麻→麻），折叠为单 A；在 `mergeNegation` **之前**执行。
- 固定功能化词表：是不是 / 要不要 / 会不会 / 能不能 / 可不可以 → 整词作功能词丢弃。
- 回归保护：真否定（不疼了→不+疼、不是的→不是、不开心、不舒服、别着急、别摔倒）逐条验证不受影响。
- 阶段 B 验收：**4 处 forbidden → 0**，真否定样本零回归。

## 五·五、LLM 接入决策（暂缓，数据触发）

**结论：P1-P3 阶段不接入 LLM。**

依据（证据核实）：
- 当前 15 处未召回、4 处反转违反、33 个噪声**全部为确定性问题**（复合词拆散 / 正反问 / 量词后缀 / 趋向补语），无一条需要语义理解才能映射；
- 生产侧 `EXAMPLE_PHRASES`（10 句）全部在 golden 集内，已知输入面 100% 可被规则覆盖；
- 接 LLM 引入云调用成本、2~3s 延迟、健康数据隐私风险，现阶段无可证明的边际价值。

接 LLM 前的零成本替代（优先做）：
1. **同义词闭环扩展**：长尾口语表达（没胃口→不想吃、睡不着、走不动…）补进图符 synonyms；
2. **纠错数据回流**（txt 路线 P3）：接收页换图/删除/重排 → 沉淀 `(句子, 用户最终图序列)` → 自动补同义词。

**数据决策点（阶段 C 收尾执行）**：把评估集扩到真实输入（历史记录/自由输入/语音转写），量化残差率——
- 残差为「缺同义词/缺图」→ 继续词库闭环，不接 LLM；
- 残差 ≥2-3% 且集中在语义级（同义改写/口语省略/错别字/方言）→ 再按 `接收分词优化.txt` P2 骨架接：触发式（matchRate 阈值）+ 硬校验（token 拼接还原原文）+ 缓存 + 超时回退，健康数据走云函数合规端点。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| FMM 过合并（某句被贪心合并出错误整词） | 全量 diff 必查；必要时 maxLen 降到 3 或加保护词 |
| 功能词误伤（我们/们 误伤 我/你） | 丢弃集只含整词 我们/咱们，不动单字代词 |
| 整句单 token 反作弊 | 贪心不会把整句合成一词（除非整句恰为图库词，如 我不明白——本就该整体出图）；反作弊逻辑维持 |
| 贪心新引入噪声 | 阶段 C 全量 diff 逐条核对 |
