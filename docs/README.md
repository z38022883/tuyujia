# 图语家 · 文档索引

本目录是图语家项目的文档 source of truth。项目为单微信小程序工程（Taro 4 + React + 微信云开发，2026-08-11 起废弃 monorepo 三端方案）。

## 目录结构

```
docs/
├── 申报材料/            # 对外申报与支撑材料
├── 算法优化/            # 接收算法的指标口径、机制图、迭代历史
│   ├── 第一版-两轮四次迭代/   # 已冻结的第一版迭代记录归档
│   └── 第二版-留出集与中医词汇/ # 进行中：留出测试集 + 中医药词汇扩充
├── 产品方案/            # 功能设计方案（康复训练 / 程度分级）
├── 参考资料/            # 外部文献
└── 归档-monorepo时期/    # 已废弃文档，仅历史追溯，勿作为开发依据
```
