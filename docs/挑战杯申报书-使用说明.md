# 六、使用说明

## （一）小程序组成及结构

"图语家"采用**三层架构**设计（前端交互层—业务逻辑层—数据层），各层职责分离、协同运作，整体结构如下图所述。

### 1. 前端交互层

前端交互层基于 Taro 4 跨端框架（React + TypeScript）构建，一套代码同时支持微信小程序端与 Web 端运行，主要包含三大交互模块。

#### 1.1 表达模块

表达模块是患者主动沟通的核心入口，服务于失语症患者的"我想说"场景。页面自上而下由五个功能区组成：

- **分类导航栏**：以层级方式展示图符分类（人物、动作、食物、地点、感受等），支持逐级进入与返回，帮助患者快速定位目标图符；
- **图符网格**：以大按钮卡片形式平铺展示当前分类下的图符，图标大、间距宽，降低误触率，适配手部精细动作受限的患者；
- **选中句条**：横置于页面上方，实时显示患者已点选的图符序列，支持**拖拽重排、单点删除**，所见即所"说"；
- **候选句面板**：患者点选图符后，系统在底部自动生成若干条通顺的候选语句，患者点选即可播报，免去逐字拼句的负担；
- **播放与收藏**：候选句支持一键语音播报，并可将当前图符组合收藏为"常用语"，供下次快速调用。

此外，模块根据患者沟通程度（重度/中度/轻度）动态调整页面提示语，如重度患者显示更简短的单图引导提示，减少认知负荷。

#### 1.2 接收模块

接收模块服务于"家属想对患者说"的场景，将健康人的自然语言转换为患者可理解的图符序列，实现双向沟通闭环。

- **文字输入区**：提供输入框及若干高频示例短语（如"吃饭""喝水""休息"），方便家属快速上手；
- **一键转换**：点击"转换为图片"按钮，系统自动将整句文字解析为图符序列；
- **图符结果展示**：转换结果以图符卡片横排展示，每张卡片标注匹配类型（精确匹配/同义词匹配等），未匹配的词以文字卡片形式保留原样；
- **结果编辑**：家属可对结果中的每张卡片进行**左右移动、更换图符、删除**三种操作，确保呈现给患者的句子准确无误；
- **展示模式**：点击"展示给患者"，页面切换为大图横排的全屏展示，并自动语音朗读整句，患者"看得见、听得着"。

#### 1.3 设置页面（"我的"）

设置页面集中管理患者档案与个性化参数：

- **沟通程度档案**：登记患者当前失语严重程度（重度/中度/轻度），驱动全应用的分级适配；
- **语音设置**：朗读语速滑块（0.5x–2.0x 无级调节）、音色选择；
- **交互偏好**：「选词后自动朗读」开关，满足不同患者的听觉辅助需求；
- **语音试听**：内置"测试语音"按钮，设置完成后可即时试听效果；
- **数据管理**：收藏短语、表达历史的查看与清理，微信端登录后数据自动云端同步。

### 2. 数据层

#### 2.1 核心词汇库

核心词汇库（lexicon）是接收模块"文字→图符"转换的匹配基础，其结构为：

- 每个词条包含**中文主词、同义词组、所属分类**三要素，同义词组显著提升口语化输入的匹配命中率（如输入"吃饭"与"进食"均可命中同一图符）；
- 词汇按生活场景分类组织，覆盖失语症患者日常高频沟通需求；
- 词条支持运行时动态检索，单次查询为内存级操作，无网络延迟。

#### 2.2 AAC 图库

图库采用国际通行的 **ARASAAC 开源图符体系**（全球应用最广泛的 AAC 图形符号库），并完成本地化整理：

- 共收录 **278 个图符**，全部为高辨识度白底象形图，符合认知障碍人群的视觉理解习惯；
- 图符按分类体系组织（categories），与表达模块的分类导航一一对应；
- 图符数据随包内置（seed 数据），核心浏览功能离线可用；图片资源按需加载，兼顾包体积与加载速度。

### 3. 业务逻辑层

#### 3.1 表达接口

表达接口承担"图符序列→自然语句→语音输出"的转换管线：

- **智能组句**：患者点选图符后，系统基于自然语言规则即时生成候选语句（点选"我/喝/水"→"我想喝水"），并按语序自动排列；
- **语音合成（TTS）**：候选句经语音合成引擎播报，语速、音色由用户设置驱动；
- **数据持久化**：每次成功表达自动写入表达历史；收藏操作同步写入本地存储与云端数据库（saved_phrases 集合），换机不丢数据。

#### 3.2 接收接口

接收接口实现"自然语句→图符序列"的逆向转换，采用**四层级联匹配算法**：

1. **分词解析**：对输入文本进行中文分词，自动合并否定词（如"不""没有"）、过滤虚词（"的""了"等），保留语义实词；
2. **精确匹配**：分词结果直接命中图库词条；
3. **同义词匹配**：未命中时查找词汇库同义词组二次匹配；
4. **词库/包含匹配**：进一步通过核心词汇库及字符串包含关系进行模糊兜底；
5. **匹配率反馈**：转换完成后展示本次匹配率，未命中词保留文字原样，保证信息不丢失。

#### 3.3 分级适配接口

分级适配接口依据失语症严重程度（参照西方失语症成套测验 AQ 评分体系）实现"一次建档、全局适配"：

- **重度**（AQ ≤ 50）：界面侧重单图短句交互，提示语精简；
- **中度**（AQ 51–75）：支持短句组合与候选句选择；
- **轻度**（AQ 76–93.8）：开放完整组句、长句表达；
- 分级同时驱动**康复训练模块**的题库难度（听理解/口语表达/阅读/书写四维度）与**家庭沟通支持指引**（每级配套不同的家属沟通策略），实现训练强度与沟通辅助的统一适配。

## （二）使用教程及操作指引

### 1. 准备工作

- 一部安装了**微信**（8.0 及以上版本）的智能手机；
- 网络连接（图符图片加载与云端同步需要联网；核心图库与历史数据已本地缓存，弱网环境仍可正常使用主要功能）；
- 获取小程序：扫描项目展示的小程序码，或在微信中搜索小程序名称"图语家"即可打开，无需下载安装。

### 2. 首次使用设置

首次打开小程序后，建议家属协助患者完成以下设置（进入底部 Tab「我的」页面）：

1. **登记沟通程度**：在患者档案中选择当前程度（重度/中度/轻度）。该设置将自动调整表达模块的界面提示与康复训练难度，如暂不确定可先选择"中度"，后续随时修改；
2. **调节语音参数**：拖动语速滑块选择适合患者的朗读速度（认知负荷较高的患者建议使用较慢语速）；点选偏好的音色；
3. **开启自动朗读**（可选）：开启后，患者每点选一个图符即朗读对应词语，提供即时听觉反馈；
4. **试听确认**：点击"测试语音"按钮，确认播报效果符合患者需要。

设置即时生效、自动保存，无需重复配置。

### 3. 表达模式使用

表达模式用于患者主动向他人传情达意，典型操作流程如下：

1. 进入首页，点击「表达」卡片进入表达模块；
2. 在**分类导航栏**中点选目标分类（如"食物"），图符网格即展示该分类下的所有图符；
3. 患者点选需要的图符（如"我""喝""水"），图符依次加入上方的**选中句条**；点错可单击该图符删除，长按拖动可调整顺序；
4. 点选完成后，页面底部自动出现**候选语句**（如"我想喝水"），患者点选最贴切的一条；
5. 系统即时**语音播报**该句子，沟通对象即可听见；如开启了自动朗读，每个词的点选过程也会有语音跟读；
6. 高频句子可点击**收藏**保存为常用语，下次在收藏夹中一键调出，无需重复点选；
7. 每次成功表达自动记入「历史」模块，家属可按时间回顾患者的表达情况。

### 4. 接收模式使用

接收模式用于家属将话语转化为患者更易理解的图符形式，操作流程如下：

1. 首页点击「接收」卡片进入接收模块；
2. 在输入框中输入要表达的话（如"我们中午吃面条"），或直接点击下方示例短语快速填入；
3. 点击**「转换为图片」**按钮，系统自动完成分词与图符匹配，页面即展示转换后的图符序列；
4. 检查转换结果：对不满意的图符，可点击卡片进行**更换**（从候选图符中另选）、**移动**位置或**删除**；未匹配的词语会以文字卡片形式保留，信息不丢失；
5. 点击**「展示给患者」**，页面切换为全屏大图展示，并自动朗读整句；
6. 将手机递给患者观看，即可完成一次"图符化"的沟通。

### 5. 分级切换

随着病情康复进展，患者能力会发生变化，分级切换操作支持全程动态适配：

1. 进入「我的」页面，在患者档案中点选新的沟通程度（重度↔中度↔轻度），**即时生效**；
2. 表达模块的界面提示语将随程度自动调整：重度以单图引导为主，轻度则开放完整组句；
3. 进入「康复训练」模块，可进一步在"训练等级"卡片中切换重度/中度/轻度题库，各等级对应不同的训练维度组合与时长建议（重度每次 ≤ 20 分钟、少量多次；中度 20–30 分钟；轻度约 30 分钟）；
4. 切换等级后，「家庭沟通支持」中的家属沟通策略指引也会同步更新，帮助家属采用与患者当前能力匹配的交流方式；
5. 康复训练模块另设**训练记录**页，自动统计完成次数与平均正确率，为复诊时向医生反馈康复进展提供数据依据。
