## 留出集纪律（本版铁律）

1. 留出集句子不驱动任何算法/词库改动；失败句一经触发修复即视为"污染"，报告注明、下次冻结轮换。
2. 标注口径修正（如 tst-022 喝茶→p_tea）不算污染，但只在冻结版本切换时应用，不边跑边改。
3. 开发集此后只做零回归验证，不再调优。
