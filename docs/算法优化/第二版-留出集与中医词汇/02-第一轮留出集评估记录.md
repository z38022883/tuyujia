## 一、本轮做了什么

1. **候选词探测**：26 个中医候选词 × ARASAAC 中/英多链检索 + 首选图逐一目检，错图词再拉全量候选深挖，共目检 55 张图 → 草案文档。
2. **用户筛选决议**（2026-11-03）：
   - 中药 → 草药店图 `tcm_herbs`（#26126）；
   - 膏药 → 贴药贴图 `tcm_plaster`（#29024）；
   - **手绘待办**：泡脚（ARASAAC 候选图 #25845 与洗澡近似，弃用）、拔罐、艾灸、把脉、热敷。
3. **词库落地**（`scripts/golden/fill-tcm-gaps.mjs`，幂等）：
   - 新增 17 个图符，图库 **310 → 327**；
   - 同义词闭环 5 处：怕冷→p_cold、口干→p_thirsty、乏力→p_tired、中医→p_doctor、不舒坦→p_uncomfortable；
   - **一词两图防线实战**：原计划给 p_uncomfortable 闭环"不舒服"，落库前发现 `p_unwell` 的 label 就是"不舒服"（既有图 #37183），已撤回——只保留 不舒坦，避免同词双图降精度。
4. **词表索引重建**：`build-lexicon-index.cjs` → **737 → 808 词**，新词全部可解析。
5. **留出测试集冻结**：`scripts/golden/test-set.json`（schema v2，30 句 = 中医调理 18 + 日常 12，87 个内容词计分项）。成稿时替换 5 处（原因记录在集内 notes 与句级 note）：
   - tst-015 泡脚句 → 撤（泡脚转手绘），编号保留不复用；
   - tst-020 早上好 → 晚上好（与 dev rec-021 完全撞车）；
   - tst-027 几点了 → 药几点吃（与 rec-053 现在几点 近重复）；
   - tst-029 我要去医院 → 想回家（与 rec-019 我们要去医院 近重复）；
   - tst-030 今天下雨 → 明天下雨（与 rec-084 逐字重复）。
6. **harness 升级**：
   - `run-golden.ts` / `check-golden-keys.mjs` 增加数据集文件参数（默认仍是开发集）；
   - checker 增加 **altIds 词形闭环兜底**：v1 遗留的 rec-065（走→p_walk，词形由 altIds p_go 覆盖）属设计内歧义，此前会被误报为未闭环。
7. **双集评测**（本轮对留出集暴露的问题**零修复**）。

## 三、留出集暴露的问题（逐条归因，本轮不修）

### A. 算法靶子（1 类）

| 句 | 现象 | 根因 |
|---|---|---|
| tst-007 你怕不怕冷 | 召回 2/2，但预期外出 怕(p_afraid)，且出 **不(p_no) = 本轮唯一反转违反** | 短式 A不A+宾语（怕不怕+冷）：`A_NOT_A_FIXED` 固定短语表只收 是不是/要不要/会不会/能不能/可不可以，通用折叠未覆盖"怕不怕"结构，不(p_no) 泄漏。dev 的 4 例正反问全是 A不A 独立成句（饿不饿/麻不麻），掩盖了此类结构 |

### B. 词库靶子（3 类）

| 句 | 现象 | 根因 |
|---|---|---|
| tst-023 想洗个澡，水要热的 | 洗澡 未召回，误出 p_wash_hands | p_wash_hands 同义词含裸"洗"，"洗个澡"被拆成 洗(p_wash_hands)+个(丢)+澡(无图)；p_shower 缺 洗个澡/冲澡/泡澡 等变体 |
| tst-019 背上痒，帮我挠一挠 | 多出 d_above；帮/我 未召回、多出 p_help_me | "上"方位词在库（d_above）被"背上"触发；p_help_me 同义词含"帮我"整词吃掉 帮+我 |
| tst-009 / tst-028 | 多出 p_give / p_yes | 给→p_give、有→p_yes 均为在库词，"给您""有点"触发了词库映射（dev 无此类词形，未暴露过） |

### C. 标注口径修正候选（下一冻结版应用，非数据/算法问题）

| 句 | 修正 | 依据 |
|---|---|---|
| tst-022 晚饭后喝茶吗 | 喝茶→p_tea（整词期望），替代 喝+茶 拆分 | **整体图优先**既定原则（同 rec-002 喝水→p_water 先例）；p_tea 同义词本就含"喝茶"，首版标注未对齐该原则 |
| tst-019 帮我挠一挠 | 帮我→p_help_me（altIds p_help），替代 帮+我 拆分 | p_help_me 语义即"帮我"，输出合理；与整体图优先原则一致 |

### 污染纪律状态

本轮**未做任何针对性修复**，30 句全部保持"干净"。上述 A/B 类进入第二版下一轮靶子清单；修复落地时按纪律在报告中注明被污染句子并轮换新句。
