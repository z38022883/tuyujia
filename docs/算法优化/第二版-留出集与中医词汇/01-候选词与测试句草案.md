## 一、探测方法（可复现）

1. **词库现状核对**：候选词逐一查 `_lexicon-index.json`（737 词），已覆盖的走同义词闭环，不新增图。
2. **ARASAAC 真实检索**：`api.arasaac.org` 中文检索 → 无结果时英文兜底 → 命中后逐一**下载目检图义**（首条结果 ≠ 图义正确：英文 pulse 命中的是"豆类"、hot water bottle 命中的是"轮船"）。
3. **不合格词多候选深挖**：错图词拉取全部/前 4 候选人工比对，共目检 **55 张图**。

- 探测脚本：`scripts/golden/probe-tcm-pictograms.mjs`（全量探测）、`scripts/golden/probe-tcm-alternates.mjs`（错图词深挖）
- 原始结果：`scripts/golden/_tcm-probe-result.json`
- 目检图片缓存：`.tmp-tcm-img/`（55 张，筛选通过后删除）

## 五、排除清单与理由

| 词 | 理由 | 备注 |
|---|---|---|
| 艾灸 | ARASAAC 无图（艾灸/灸/moxibustion/moxa/cauterization 全部 0 结果） | 特色词，但宁缺毋滥；如需可走手绘，本版不做 |
| 拔罐 | cupping therapy 81 条结果全是奖杯/量杯/马克杯等无关图 | 同上 |
| 把脉 | 无对应图；最接近的仅袖带血压计，与 量(m_measure，同义词含量血压) 冲突 | 放弃，避免一词两图 |
| 热敷 | 无准确图（heating pad 首条为轮船） | 外治法由 膏药/泡脚 覆盖 |
| 忌口 | 首条为"减肥前后对比"，图义偏差 | 由 否定+吃 的既有否定管线表达 |
| 没胃口 | 首条为"想到食物的笑脸"（=饥饿，反义） | 避免反义图；词库已有 饿(p_hungry) |
| 上火/湿气重/阴虚/阳虚/气虚/血瘀/经络/穴位 | 抽象概念不可图示 | 保持"高语义透明度、图库缺口 0"两个申报口径不被稀释 |

> 这批排除词**本身就是答辩素材**：它们是真实场景残差的来源，支撑"何时才需要 LLM"的数据决策点叙事（见方案 5.5 节）。
