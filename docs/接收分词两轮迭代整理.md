## 二、第一轮：20 条小集三步算法迭代

> 记录文件：`scripts/golden/baseline-v0.md` / `baseline-v1.md` / `baseline-v2.md`
> 被测代码：`src/utils/text-to-image-matcher.ts` + `src/utils/segment-text.ts`（Intl.Segmenter 分词 + 5 级匹配）
> 复现：`node -r ts-node/register/transpile-only -r ./scripts/golden/register-alias.cjs ./scripts/golden/run-golden.ts`

### 迭代① v0 — 首次基线
- 记录：`baseline-v0.md`，20 条，39 个有图内容词。
- 结果：召回 29/39（74.3%）、matchRate 0.846、整句单 token 反作弊 1、缺口 1（`抬`）。
- 暴露 5 类问题：
  1. **否定词拆出正面词 → 语义反转**（最高优先）：不开心→p_happy、不舒服→p_no；
  2. **功能词误出图**：需要/要 → p_need_want（4 条）；
  3. **补语/趋向误出图**：起来/下来 → p_come；
  4. **分词粒度**：头疼被合成单 token；
  5. **整句单 token** 反作弊 1 次。

### 迭代② v1 — P1 阶段一：否定合并 + 功能词过滤
- 改动（收敛在 matcher 预处理层，segmentText 未动）：
  1. `mergeNegation()`：单字否定词与其后 token 合成否定复合词，防语义反转；
  2. `FUNCTION_WORDS`：需要/要/该/应该/感觉/好像/起来/下来/上来/上去/下去 剔除；
  3. 反作弊收紧：仅"整句原样成单 token"才计。
- 结果：31/39（**79.4%**，+5.1pp）、语义反转消除、p_need_want 误图清零、反作弊 0。
- 剩余 miss 7 条，根因统一：**分词由《Intl 语言习惯》而非《图库词表》驱动**（喝水/睡了/吃饭/来看/把手 等合成/拆分与词表不符）。

### 迭代③ v2 — P1 阶段二：图库贪心拆解
- 改动：
  1. `VOCAB` 图库词表；`splitByLexicon()` 正向最大匹配（maxLen 4）；
  2. `matchToken()` 抽取 5 级匹配为可复用函数；
  3. 未命中 token 用词表拆出 ≥2 词再匹配；已命中整体图（头疼/肚子疼）一律不拆；
  4. `MINOR_WORDS` 丢弃单字虚词碎片（了/的/吧/把/着…）。
- 结果：35/39（**89.7%**，累计 +15.4pp），救回 睡了/来看/把手 3 条。
- 剩余 miss 3 条（喝水/头疼/吃饭）为**图库整合词粒度冲突**，贪心不拆；残留 趋向补语"来"误出 p_come、代词"我们"拆出"我"→p_i 两处噪声。
- 遗留待拍板：整合词用整图还是原子词；趋向来/去识别；rec-008 期望口径。

## 三、第二轮：评估集扩容 + 图库扩充 + 算法重构

> 记录本体：`docs/图库扩充与golden评估集优化记录.md`
> 方案存档：`docs/接收分词算法优化方案.md`
> 本轮内部可拆为 4 个子阶段（2026-09-09 ~ 09-10）：

### 子阶段 1 — golden 评估集优化（20 → 85 条）
- schema v1 → v2；**85 条 / 14 场景**（问候礼貌 5、饮食 9、排泄卫生 6、症状医疗 14、情绪 7、动作活动 7、指令照护 9、地点出行 5、人物 5、时间 4、沟通修复 5、应急安全 3、否定应答 4、天气环境 2）。
- 每条新增 `scenario`/`sentenceType`；否定陷阱句带 `forbiddenIds` **反转断言**；**整体图优先**标注原则。
- 评估升级（`run-golden.ts`）：按场景聚合召回/精度、反转违反计数、缺口清单、反作弊修正。
- 新基线（补图前）：召回 122/138（89.7%）、精度 76.7%；沟通修复场景仅 33.3%；5 处反转违反。

### 子阶段 2 — 图库扩充（295 → 310）
- 用 ARASAAC 官方检索接口按中文（英文兜底）补齐 15 个缺口词（p_hello/p_goodbye/p_sorry/p_hard_work/m_measure/m_check/e_mood/p_clock/m_injection/p_open_mouth/m_deep_breath/p_raise_hand/a_support/pl_ambulance/w_rain）。
- `e_relieved` 追加同义词 `没事/没关系` 闭环否定应答缺口。
- 可复用脚本：`scripts/golden/fill-arasaac-gaps.mjs`（NEW 数组扩展即可再补图）。

### 子阶段 3 — golden 回填 + 词形闭环
- 16 处缺口回填真实图符 id；3 条升级为整体图期望（你好/张嘴/深呼吸）。
- 新增 `scripts/golden/check-golden-keys.mjs` 三层核对（无缺口/无断链/词形闭环）：
  - rec-065 走→p_walk 判定**设计内歧义**（altIds:[p_go] 可接受），不加词避免一词两图；
  - rec-069 别着急→r_no_rush 词形缺口，**已闭环**补同义词，同时消除该句 p_anxious 反转。
- 闭环后：召回 133/148（89.8%）、精度 80.1%、matchRate 0.897、反转 5→4、缺口 0。

### 子阶段 4 — 接收分词算法优化（阶段 A/B/C）
- **根因盘点**（`plan-evidence.mjs` 逐句证据）：
  - 未召回 15 处 = 复合词被 Intl 拆散，且 **100% 已在词库**（纯切分粒度问题）；
  - 反转违反 4 处 = A不A 正反问（饿不饿/要不要/麻不麻/是不是）被 mergeNegation 误合；
  - 精度噪声 33 个 = 复合词半截图（~25）+ 一下→d_below + 坐下来→p_come。
- **阶段 A（P1 词表贪心预分词）**：`vocabSegment()` FMM（maxLen 4）替换 Intl 主切分；管线 vocabSegment → foldAorNotA → mergeNegation → 去功能词 → 5 级匹配；`DROP_WORDS`（一下/我们/咱们）；p_sit 补同义词 坐下来。
  - 结果：召回 147/148 = **99.3%**、精度 96.7%、沟通修复 33.3%→100%、14 场景除饮食外全 100%。
- **阶段 B（P2 正反问折叠）**：`foldAorNotA()` A不A→A（在 mergeNegation 之前）；是不是/要不要/会不会/能不能/可不可以 整词功能化。
  - 结果：4 处 forbidden → **0**、精度 **100%**、并消灭 是不是→p_yes_response 新噪声；真否定样本（不疼了/不是的/不开心/别着急/别摔倒）零回归。
- **阶段 C（P3 收敛）**：rec-002 喝水 改整体图期望（与 rec-004 吃药口径一致），分母 148→147。
  - 结果：召回/精度**双 100%（147/147）**、85 条零回归。
- **LLM 决策（暂缓，数据触发）**：当前残差全部是确定性规则可覆盖问题，无语义级残差；接入前提 = 扩真实输入集→量化残差≥2-3% 且集中在语义级。优先做同义词闭环扩展 + 纠错数据回流。

### 附带：表达侧词板同步（P0/P1/P2）
- P0：新图符在表达模块可见（categories.json 补 quickchat/actions、home 板置顶、中度词板 16→20、SEVERE_EXPRESS_WORDS 派生）。

- P2：激活「最近使用」板入口（recent 瓦片，从持久化表达历史派生，零新增存储键）。

## 六、遗留决策与下一步

1. **LLM 接入**：暂缓，按数据决策点执行——扩真实输入集（历史记录/自由输入/语音转写）→ 量化残差 → 仅当语义级残差 ≥2-3% 再启动触发式 LLM 重切分。
2. **零成本替代优先**：同义词闭环扩展（长尾口语：没胃口→不想吃、睡不着、走不动…）；纠错数据回流（用户换图/删除/重排 → 自动补同义词）。
3. **防过拟合**：评估集可补充高频变体句（吃饭了没 / 水杯 / 疼不疼）验证 P1 贪心不回归。
4. **第一轮遗留口径**（已被第二轮整体图优先原则覆盖）：整合词用整图 vs 原子词，已按"整体图优先"拍板。

## 八、图5-1 修订记录（2026-09-20）

图5-1 于本日两次改版，终版为**横向五阶段流水线**（参考「全本地 / 确定性 / 零模型成本 中文口语理解管线」
的分列机制图版式）：左侧输入列 → 五列阶段（每列 = 标题条 ＋ 机制标签 ＋ 纵向子流程框 ＋ 要点 ＋ 结论框）
→ 右侧输出列，顶/底各一条横幅，列间在结论框高度上以箭头串联。

**逐列内容**（均与 `src/utils/text-to-image-matcher.ts` 对齐）：

| 列 | 机制标签 | 纵向子流程 |
|---|---|---|
| ① 词表贪心预分词 `vocabSegment()` | 正向最大匹配 FMM；切分词表 = 图库词 737 ＋ 功能词 ＋ 丢弃词 | 从句首扫描 → 最长词长 4→1 倒序试命中 → 整词切出 → 未命中出单字 → 至句尾 O(句长×4) |
| ② 正反问折叠 `foldAorNotA()` | 检测 A不A（甲不甲 / A没A），非真否定 | 三分窗口扫描 → A不A 折叠为 A → 固定短语整词功能化 → 真否定不折叠 → 交后续步骤 |
| ③ 否定合并与功能词剔除 `mergeNegation()` | 单字否定词 ＋ 相伴词 → 复合词 | 否定前缀合并 → 功能词 11 词 → 切后丢弃词 8 词 → 碎片 15 字 → 保留词进入匹配 |
| ④ 五级级联匹配 `matchToken()` | L1→L5 逐级下探，命中即停；阶段基分 400 / 300 / 200 | L1 精确 → L2 同义词 → L3 词库同义词链 → L4 包含匹配 → L5 拆解兜底；每级「否」下探、「是」出图 |
| ⑤ 输出去噪与呈现 `matchTextToImages()` | 编号去重 ＋ 反作弊判定 ＋ 人工修正闭环 | 编号去重 → 整句单单元反作弊 → C/N 指标 → 接收页修正 → 历史回流 |

每列底部为结论框（该阶段输出物），列间箭头指向下一阶段；顶横幅给出管线定位，底横幅给出代码路径、
数据规模与 golden 指标（召回 100% 147/147 · 精度 100% · 反转 0 · matchRate 0.966）。
